# Code of Conduct

SysMonitor aims to be a practical, respectful open-source project.

## Expected Behavior

- Be kind and direct.
- Assume good intent, but accept corrections gracefully.
- Keep issue and pull request discussions focused on the project.
- Give useful context when reporting bugs or reviewing code.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeated off-topic or disruptive comments.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject pull requests; or block participants when needed to keep the project safe and useful.

To report a conduct issue, contact the maintainer listed in `LICENSE`.
